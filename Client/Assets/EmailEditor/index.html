Modèle d'e-mail

0 caractère

Utilisez les variables [PRENOMS], [HEURE], [DATE_LONGUE], [DATE_COURTE] et [CABINET] pour personnaliser vos e-mails. Les balises historiques ([PrenomsSMS], [Heur:], etc.) restent valides.

Le modèle est sauvegardé dans l'application quand vous cliquez sur "Enregistrer le modèle e-mail".
